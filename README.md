# Архив OCR

Веб-приложение для оцифровки рукописей и машинописного текста из архива.
Всё работает в браузере, сервера нет, бесплатно, без ключей и регистрации.
Фото и документы не покидают компьютер.

## Что умеет

- Загрузка фото (JPG, PNG, WebP) и PDF: перетаскивание, выбор файла, вставка из буфера (Ctrl+V).
- Очередь страниц, пакетное распознавание по одной странице, с паузой и кнопкой «Стоп».
- Предобработка на Canvas: градации серого, контраст, бинаризация по Отсу, апскейл до ~300 DPI, поворот.
- Распознавание через Tesseract.js v6: языки rus / eng / rus+eng, настройка PSM, один воркер на сессию, прогресс в %.
- Три режима качества для слабых ПК: экономный (до 1200 px), обычный (до 1800 px), максимальное качество (до 2400 px).
- Редактор: слева фото, справа редактируемый текст. Неуверенные слова подсвечены жёлтым и кликабельны в обе стороны: слово → рамка на фото, рамка на фото → слово в тексте. Статистика: символы, слова, уверенность, время.
- Экспорт в .txt, .docx и копирование в буфер обмена.
- Кнопка «Пример для проверки» — генерирует на Canvas страницу-образец архивной справки с известным текстом.
- Режим «Помощник транскрибации» для рукописей (см. ограничения ниже).
- Бенчмарк для подбора быстрого режима под конкретный компьютер (см. ниже).

## Как запустить локально

Просто откройте `index.html` в браузере. Интернет нужен только при первом запуске:
движок Tesseract.js и языковые данные скачиваются с CDN (~10–15 МБ) и кэшируются браузером,
дальше приложение работает офлайн.

Если браузер блокирует `file://` для модулей — запустите локальный сервер одной командой:

```bash
npx serve .
# или
python3 -m http.server 8000
```

и откройте http://localhost:8000 (или адрес, который покажет `serve`).

## Как включить GitHub Pages

1. Загрузите папку в репозиторий (например, `hustlerwhpp/archive-ocr`).
2. В репозитории: Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу `https://hustlerwhpp.github.io/archive-ocr/`.

Сборки нет — это статичный сайт из трёх файлов (`index.html`, `app.js`, `styles.css`).

## Бенчмарк

Секция «Бенчмарк» в приложении:

- **Экспресс-тест (~2 сек)** — 5 замеров предобработки на разных размерах. Работает полностью офлайн, без движка OCR.
- **Полный бенчмарк** — 3 последовательных прогона на образце справки: экономный 1200 px с бинаризацией, обычный 1800 px с бинаризацией, без бинаризации. Замеряются время, точность по известному тексту образца и уверенность движка. Прогоны идут по одному, с паузами и кнопкой остановки, чтобы не перегружать слабый ПК.
- В конце — авто-рекомендация самого быстрого режима без заметной потери точности и кнопка «Применить».

Если движок недоступен (например, заблокирован CDN), полный бенчмарк покажет понятную ошибку и предложит экспресс-тест.

## Ограничения по рукописям — честно

Tesseract обучен в основном на печатном тексте. Рукописный текст, особенно курсив,
старая орфография (ѣ, і, ъ) и неразборчивый почерк, он читает плохо — с большим числом ошибок.

Поэтому рукописи в приложении оформлены как **помощник транскрибации**: движок даёт черновик,
а человек сверяет его с фото построчно и правит вручную. Автоматическая оцифровка рукописей
здесь НЕ обещается.

## Что доделывать дальше

- **PP-OCRv6 Cyrillic** — локальная нейросеть для русского печатного и рукописного текста
  (модели Metrika Labs `PP-OCRv6 Tiny/Medium rec_cyrillic`, ONNX, CPU). Это главный следующий шаг:
  она заметно лучше Tesseract на фото и на разборчивом рукописном русском, а по весу подходит
  для слабых ПК (детектор ~10 МБ + распознаватель ~20 МБ).
- Построчная сегментация для рукописей (резать страницу на строки до распознавания).
- Сохранение проектов в IndexedDB (сейчас текст живёт только до перезагрузки страницы).
- Пакетный экспорт всех страниц в один .docx.
