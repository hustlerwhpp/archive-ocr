Архив OCR

Оцифровка рукописей и машинописного текста — полностью в браузере, без сервера. Фото не покидают этот компьютер.

Бесплатно, без ключей и регистрации. Первый запуск скачивает движок и языковые данные (~10–15 МБ), дальше работает офлайн из кэша браузера.

На iPhone/iPad: «Поделиться» → «На экран “Домой”» — приложение появится как отдельное и будет работать офлайн. Доступна новая версия приложения.

Внимание: Tesseract плохо читает рукописный текст, особенно курсив и старую орфографию. Результат ниже — только черновик для ручной сверки с оригиналом, а не автоматическая оцифровка рукописи.

Бета: аккуратный почерк читает хорошо, курсив — с ошибками. Сверяйте с фото и правьте вручную. Для переключения обратно на печатный текст выберите движок «Печать (Tesseract)».

При первом распознавании скачиваются модели: детектор строк ~1,7 МБ + распознаватель Tiny ~2,4 МБ (или Medium ~60 МБ). Модели кэшируются в браузере (IndexedDB) — повторный визит без скачивания, дальше работает офлайн. Бинаризация по Отсу в этом режиме не применяется: синие чернила и курсив от неё страдают.

1. Загрузка

Перетащите сюда фото (JPG, PNG, WebP) или PDF,
или нажмите, чтобы выбрать файлы.
Вставка из буфера тоже работает: Ctrl+V

Готово к работе. Движок загрузится только при первом распознавании.

Очередь страниц

    Распознавание идёт по одной странице, с паузой между страницами, чтобы не перегружать компьютер.

    2. Проверка и правка

    Выберите страницу в очереди — здесь будет фото, а справа текст.

    Здесь появится распознанный текст. Неуверенные слова будут подсвечены жёлтым — нажмите на такое слово, чтобы увидеть его место на фото.

    Клик по подсвеченному слову — рамка на фото. Клик по рамке на фото — подсветка слова в тексте.

    3. Бенчмарк — подобрать быстрый режим для этого компьютера

    Бенчмарк прогоняет образец архивной справки на разных настройках и выбирает самый быстрый режим без заметной потери точности. Прогоны идут по одному, с паузами, — компьютер не перегружается.

    Всё считается локально. Нет сервера, нет отправки фото, нет платных ключей.

    Ограничение: рукописи Tesseract читает плохо — используйте режим «Рукопись (PP-OCRv6, бета)» и сверяйте вручную. Курсив PP-OCRv6 тоже читает с ошибками (см. README).

    Приложение можно установить на компьютер или телефон (PWA): после первого запуска оно работает офлайн, модели кэшируются в браузере.
